# Dynamic Wumpus Logic Agent

## Overview
A Knowledge-Based Agent that navigates a Wumpus World grid using Propositional Logic and Resolution Refutation.

## Features
- Dynamic grid sizing
- Random pits and Wumpus placement
- Percept generation (Breeze, Stench)
- Knowledge Base with CNF + Resolution
- Visualization with Matplotlib

## How to Run
1. Clone this repo
2. Open `WumpusAgent.ipynb` in Jupyter Notebook
3. Run all cells to simulate the agent

## Deployment
This project can also be deployed as a web app using React + Vercel.
